# Путь веб-разработчика

Локальная обучающая платформа: от «что такое веб» до работающего бэкенда на
Python. Всё офлайн — ни одного внешнего запроса, зависимости только Flask.

**98 уроков · 10 этапов · 28 модулей · 405 упражнений · ~33 часа теории · 68 проверенных бесплатных ресурсов · 3 спринт-тренажёра на 60 вопросов**

## Запуск

Двойной клик по **`start.bat`** — он сам найдёт Python 3, один раз поставит
Flask и откроет курс в браузере на `http://127.0.0.1:5050/`.

Остановить — `Ctrl+C` в окне консоли.

Если порт 5050 занят, запустите на другом:

```bat
start.bat 5060
```

### Вручную

```bash
pip install -r requirements.txt
python app.py --port 5050 --open
```

Нужен Python 3.10 или новее. На Windows команда `python` может быть занята
ярлыком Microsoft Store — `start.bat` это обходит и перебирает кандидатов
(`py -3`, `python`, `python3`, затем типовые папки установки).

| 3 | CSS: внешний вид | базовый CSS · раскладки · дизайн-система и полировка | 11 |

| 5 | Фронтенд-практика | инструменты фронтендера · проект этапа | 4 |
| 6 | Python: язык | первые шаги · логика и коллекции · функции и ошибки · ООП и экосистема | 18 |
| 7 | Бэкенд на Flask | HTTP и REST · ядро Flask · приложение Flask | 11 |

| 10 | Продакшн и диплом | качество и безопасность · доставка кода · дипломный проект | 9 |

Каждый урок — теория (250–550 слов, без воды), разбор типичной ошибки и
упражнения трёх видов:

- **quiz** — тест с одним правильным ответом и объяснением после ответа;
- **code** — редактор с автопроверкой: Python исполняется на сервере в
  песочнице, HTML/CSS/JS проверяются в браузере;
- **task** — задание в реальном инструменте (терминал, DevTools, GitHub) с
  чек-листом для самопроверки.

Отдельный раздел — **мини-игры** (`#/games`): спринты на скорость с очками,
сериями и рекордами. Одна механика (вопрос → 4 варианта → объяснение), три подачи:

| Тренажёр | Что тренирует | Банк | Спринт |
|---|---|---|---|
| Угадай селектор | CSS-селекторы по разметке с подсвеченной целью | 22 | 75 с |
| Найди ошибку | причину бага в фрагменте HTML/CSS/JS/Python | 22 | 90 с |
| Собери раскладку | flex-свойства по живой картинке раскладки | 16 | 90 с |

Очки: 100 за верный ответ × множитель серии (до ×5) плюс бонус за скорость (до
80). Неверный ответ — −4 секунды и обнуление серии, пропуск — −2 секунды.
Вопросы и варианты перемешиваются на каждом забеге, так что зубрёжка позиций не
помогает. Управлять можно с клавиатуры (1–4, Space — пропустить, Enter — дальше),
на скрытой вкладке спринт ставится на паузу. Рекорды (лучший счёт, лучшая серия,
число забегов) лежат в таблице `game_records` и видны на карточках раздела.

Прогресс сохраняется в `data/progress.db`, черновики кода — в `localStorage`
браузера. Кнопка «Сброс» убирает и отметки уроков, и рекорды игр; вручную —
удалить файл базы.

## Честность проверок

Автопроверка бесполезна, если её можно пройти, ничего не сделав, или если
эталонное решение не проходит собственные тесты. Поэтому прогоняются оба
направления:

- **140 code-упражнений**: эталонное решение проходит все проверки —
  73 Python через песочницу (`tools/validate_content.py`), 67 HTML/CSS/JS
  через реальный раннер в браузере;
- **те же 140**: выданная заготовка проверки **не** проходит, то есть решить
  нажатием кнопки не выйдет.

У мини-игр та же планка — ответ должен быть единственно верным:

- **22 вопроса `selector`**: верный селектор попадает ровно в помеченные
  `data-target` элементы, а каждый из трёх дистракторов даёт другое множество
  (сверяется `querySelectorAll` и `insertRule` в реальном браузере). Так
  наружу выходят ловушки вроде `.toolbar :not(.spacer)`, который помечал то же
  самое, что и эталон, и однодвоеточная запись `.lead:first-line`, которая
  валидна и означает то же, что `::first-line`. Исключение помечено в банке
  полем `styling`: у `:hover` и `::first-line` множества пустые, поэтому для
  них проверяется только корректность CSS верного варианта;
- **16 вопросов `flex`**: среди вариантов ровно один совпадает с целью
  геометрически, четыре тройки различимы, и ни одна картинка не вылезает за
  карточку на ширине 205/420/600 px;
- **22 вопроса `bug`** и все три банка — структурная проверка в
  `tools/validate_content.py` (4 варианта, ответ в диапазоне, нет дублей
  вариантов, иконка есть в спрайте, цель `flex` встречается ровно раз).

Песочница Python (`runner/sandbox.py`) — два уровня: статический обход AST до
запуска и урезанный набор builtins внутри отдельного процесса с таймаутом 5 с.
Запрещены `open`, `input`, `eval`, `exec`, `global` и dunder-атрибуты вроде
`__class__` и `__globals__`; импорт — только из белого списка `SAFE_MODULES`
(25 модулей стандартной библиотеки: `math`, `json`, `re`, `datetime`,
`collections`, `itertools`, `functools`, `hashlib`, `random`, `statistics`
и другие). Это учебная изоляция для локального однопользовательского
приложения, а не защита от враждебного кода.

Проверки CSS сравнивают значение с тем, что вернёт `getComputedStyle`, поэтому
цвета пишутся как `rgb(...)`, а свойства — в camelCase. Толщину рамки Chromium
квантует до целых аппаратных пикселей, так что при масштабе экрана 125 %
`1px` приезжает как `0.8px`; раннер прогоняет ожидаемое значение через тот же
квантователь и от масштаба не зависит.

## Структура проекта

```
app.py                     Flask: страницы, API прогресса, запуск кода
runner/sandbox.py          AST-валидация + subprocess-изоляция
runner/_child.py           дочерний процесс песочницы
content/curriculum.json    этапы → модули → уроки
content/resources.json     68 бесплатных источников
content/games.json         3 спринт-тренажёра, 60 вопросов
content/lessons/*.json     метаданные урока и упражнения
content/lessons/*.md       теория урока (Markdown)
content/SCHEMA.md          формат урока, упражнения и игры
content/AUTHORING_GUIDE.md как писать уроки
static/                    SPA на ванильном JS, без сборки и CDN
static/js/games.js         движок спринтов: очки, серии, три подачи
templates/index.html       единственная страница
tools/validate_content.py  валидация всего контента + прогон эталонов
tools/check_lessons.py     быстрая проверка отдельных уроков
tools/smoke_sandbox.py     дымовой тест песочницы
```

## Для авторов контента

Перед началом — `content/AUTHORING_GUIDE.md` и `content/SCHEMA.md`. Проверка:

```bash
python tools/validate_content.py            # схема + эталоны через песочницу
python tools/validate_content.py --quick    # только схема
python tools/check_lessons.py css-05-flexbox py-10-funktsii
python tools/check_lessons.py --all
```

Валидатор возвращает ненулевой код при любой ошибке и печатает сводку. Сейчас:
`0 ошибок, 0 предупреждений`.

## Ограничения

- Сервер разработки Flask — для одного пользователя на локальной машине.
  Для публикации нужен полноценный WSGI-сервер (этап 10 как раз об этом).
- В песочнице нельзя читать файлы, запрашивать ввод и импортировать сторонние
  библиотеки, поэтому темы вроде работы с файлами, pytest и Docker проверяются
  чек-листами `task`, а не кодом.
- Примеры в теории (`examples`) не исполняются — исполняется только код
  ученика в упражнении.
