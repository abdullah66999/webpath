## WHERE: оставить только нужные строки

`SELECT` без условий возвращает всю таблицу. Чтобы отобрать строки, добавляют `WHERE`:

```sql
SELECT name, price FROM products WHERE price > 1000;
```

Условие проверяется для каждой строки: если оно истинно, строка попадает в результат. Работают привычные операторы — `=`, `>`, `<`, `>=`, `<=`, `<>` (не равно, можно писать и `!=`). Обратите внимание: равенство в SQL — это одиночное `=`, а не `==` как в Python.

## AND, OR, NOT и скобки

Условия объединяются логическими операторами:

```sql
SELECT name FROM products
WHERE category = 'чай' AND price < 500;

SELECT name FROM products
WHERE category = 'чай' OR category = 'кофе';
```

Как и в арифметике, `AND` связывает сильнее `OR`. Если смешиваете их в одном запросе — ставьте скобки, иначе однажды прочитаете условие не так, как его выполнила база:

```sql
WHERE (a = 1 OR b = 2) AND c = 3   -- скобки решают
```

`NOT` отрицает условие: `WHERE NOT category = 'чай'` то же самое, что `WHERE category <> 'чай'`.

## BETWEEN и IN: короткие формы

`BETWEEN a AND b` включает границы — это `>= a AND <= b`:

```sql
WHERE price BETWEEN 100 AND 500   -- от 100 до 500 включительно
```

`IN` заменяет цепочку `OR`:

```sql
WHERE category IN ('чай', 'кофе', 'какао')
```

## LIKE: поиск по шаблону

`LIKE` сравнивает строку с шаблоном, где `%` — любое количество любых символов, а `_` — ровно один:

```sql
WHERE name LIKE 'чай%'    -- начинается на «чай»
WHERE name LIKE '%зелёный%' -- содержит «зелёный»
WHERE name LIKE 'чай_'     -- «чай» плюс ровно один символ
```

Шаблон, начинающийся с `%`, не может использовать индекс и сканирует всю таблицу — на больших данных это медленно.

## NULL не равен ничему

`NULL` означает «значение неизвестно». Он не равен ничему — даже самому себе. Любое сравнение с NULL даёт «неизвестно», поэтому `WHERE total = NULL` не найдёт ничего. Правильно:

```sql
WHERE total IS NULL       -- значение неизвестно
WHERE total IS NOT NULL   -- значение есть
```

Отсюда ловушка: `WHERE total != 500` **не вернёт** строки, где total равен NULL, — «неизвестно» не прошло фильтр. Нужны все, кроме пятисот? Пишите `WHERE total != 500 OR total IS NULL`.

## ORDER BY: сортировка

```sql
SELECT name, price FROM products
ORDER BY price DESC, name ASC;
```

`ASC` — по возрастанию (поведение по умолчанию), `DESC` — по убыванию. Через запятую можно сортировать по нескольким столбцам: сначала по цене, равные цены — по имени. `ORDER BY` выполняется уже после отбора строк, поэтому здесь можно использовать псевдонимы из `SELECT`.

## Типовая ошибка

`WHERE status = NULL` вместо `IS NULL` — запрос молча вернёт ноль строк, и вы будете искать баг в данных, хотя он в условии. Запомните: с NULL работают только `IS NULL` и `IS NOT NULL`.
