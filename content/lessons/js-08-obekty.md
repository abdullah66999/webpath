## Объект — набор пар «ключ — значение»

Массив хранит упорядоченный список, а объект (object) — связанные данные с именами:

```js
const user = {
  name: 'Динара',
  age: 30,
  isAdmin: true,
};
```

Ключи — строки (или символы). Если ключ — корректное имя, кавычки можно не писать. Чтение и запись:

```js
user.name;          // 'Динара' — через точку
user['age'];        // 30 — через скобки: когда ключ в переменной или с пробелом
user.city = 'Омск'; // добавить свойство
delete user.age;    // удалить
```

Разница важна: `user[name]` ищет значение **переменной** `name`, а `user.name` — ключ с именем «name». Обращение к несуществующему свойству даёт `undefined` без ошибки — а вот чтение свойства из `undefined` (`user.address.city`, если адреса нет) упадёт с TypeError. Здесь и спасает `?.` из урока про операторы.

## const не замораживает объект

```js
const settings = { theme: 'dark' };
settings.theme = 'light'; // работает
settings = {};            // TypeError
```

`const` запрещает положить в переменное новое значение, но не трогать содержимое старого. Это нормально и используется постоянно.

## Деструктуризация

Деструктуризация (destructuring) раскладывает объект по переменным:

```js
const { name, age } = user;            // в одноимённые переменные
const { name: userName } = user;       // с переименованием
const { role = 'гость' } = user;       // значение по умолчанию
```

Дефолт срабатывает, только когда значение свойства — `undefined`; явный `null` или `''` его не включат. Особенно удобно деструктурировать параметры функции: `function render({ title, size = 12 })` — на вызове сразу видно, что передают.

## Перебор свойств

`for...in` перебирает ключи, но может зацепить унаследованные свойства — в простом коде его избегают. Современный способ:

```js
Object.keys(user);    // ['name', 'city', ...]
Object.values(user);  // значения
Object.entries(user); // [['name', 'Динара'], ...]

for (const [key, value] of Object.entries(user)) {
  console.log(key, value);
}
```

## Вложенные структуры

Реальные данные — матрёшка из объектов и массивов:

```js
const order = {
  items: [
    { name: 'чай', price: 250 },
    { name: 'мёд', price: 400 },
  ],
};

const first = order.items[0].name;                          // 'чай'
const total = order.items.reduce((sum, i) => sum + i.price, 0); // 650
```

Читайте такие цепочки справа налево при отладке: обычно падает то звено, которое оказалось `undefined`.

## JSON

JSON (JavaScript Object Notation) — текстовый формат обмена данными; именно в нём браузер говорит с сервером.

```js
const text = JSON.stringify(order); // объект → строка
const copy = JSON.parse(text);      // строка → объект
```

В JSON нет `undefined`, функций и комментариев: свойства с `undefined` исчезают, функции отбрасываются. `JSON.parse` на битой строке бросает ошибку. И помните: `copy === order` — `false`, объекты сравниваются по ссылке, даже если содержимое идентично.

## Частые ошибки

- `user[name]` против `user.name`: скобки ищут переменную, точка — буквальный ключ.
- Сравнение объектов через `===`: два одинаковых по содержимому объекта не равны.
- Длинная цепочка `a.b.c.d` без `?.` — TypeError на первом же пропущенном звене.
- `JSON.parse(JSON.stringify(obj))` как «глубокая копия»: undefined и функции теряются, даты становятся строками.
- Ожидание порядка ключей: числоподобные ключи ('2', '10') движок перебирает первыми и по возрастанию.
