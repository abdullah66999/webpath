## Строка — это неизменяемая последовательность символов

Начать важно с главного свойства: строки (string) в JavaScript **неизменяемы**. Никакой метод не правит существующую строку — каждый возвращает новую.

```js
const word = 'кот';
word[0] = 'К';        // молча не сработает (в строго режиме — TypeError)
word.toUpperCase();   // 'КОТ' — но word по-прежнему 'кот'
```

Отсюда правило: результат строкового метода всегда нужно куда-то сохранить — в новую переменную или передать дальше по цепочке.

## Шаблонные строки

Текст можно задавать одинарными, двойными и обратными кавычками. Обратные кавычки дают шаблонный литерал (template literal): подстановку значений через `${}` и переносы строк.

```js
const name = 'Мира';
const score = 9;

const line = `${name} набрала ${score * 10} очков`;
const multi = `первая строка
вторая строка`;
```

Внутри `${}` работает любое выражение, не только переменная. Склейка через `+` тоже не запрещена, но в длинных строках в ней легко потерять пробел: `'Имя:' + name` и `'Имя: ' + name` отличаются одним символом, который не видно.

## Длина, индексы, срез

- `text.length` — длина. Это свойство, а не метод: скобки не нужны.
- `text[0]` — первый символ. Обычные скобки не понимают отрицательные индексы: `text[-1]` вернёт `undefined`. Чтобы взять символ с конца, используйте `text.at(-1)`.
- `text.slice(from, to)` — вырезать фрагмент от `from` до `to`, **не включая** `to`. `to` можно опустить — до конца строки; отрицательные значения считаются от конца.

## Регистр и поиск

- `toUpperCase()` / `toLowerCase()` — новый регистр. Перед сравнением пользовательского ввода приводите обе стороны к одному регистру: `'Admin' === 'admin'` это `false`.
- `includes(part)` — есть ли подстрока. `startsWith(part)` / `endsWith(part)` — начало и конец.
- `indexOf(part)` — индекс первого вхождения или `-1`, если подстроки нет.

```js
const file = 'отчет.pdf';
file.includes('pdf');   // true
file.startsWith('от');  // true
file.indexOf('.');      // 5
```

## trim, split, join

- `trim()` — убрать пробелы, табы и переносы по краям. Делайте это всему, что пришло из полей ввода.
- `split(разделитель)` — разрезать строку в массив. `'a,b'.split(',')` даёт `['a', 'b']`.
- `join(склейка)` — обратная операция для массивов: `['a', 'b'].join('-')` даёт `'a-b'`.

## Строки и числа

`Number('42')` строг: любой мусор внутри — и результат `NaN`. Зато `Number('')` вернёт `0`, и это ловушка при валидации пустых полей.

`parseInt('42px', 10)` читает число до первого нечислового символа — удобно для `'42px'` и `'7 дней'`. Основание передавайте всегда: без него движок угадывает формат, и `'0x1f'` превратится в `31`, а не в строку. `parseInt('', 10)` вернёт `NaN`.

## Частые ошибки

- `parseInt('42')` без основания — работает для обычных чисел, но стреляет на строках вроде `'0x..'`. Пишите `parseInt(x, 10)`.
- Сравнение строк без приведения регистра и без `trim()`: `' Москва'` не равно `'москва'`.
- Ожидание, что `word[0] = 'К'` изменит строку, или что метод поправит её на месте.
- `'5' > '10'` даёт `true`: строки сравниваются посимвольно, а не как числа. Сначала `Number(...)`.
- `split` по разделителю, которого в строке нет, вернёт массив из одной строки целиком — проверяйте длину перед обращением по индексу.
