## Два числовых типа

Целые живут в `int`, дробные — в `float`. Разница принципиальная: `int` точен и не ограничен по размеру, `float` — приближение с фиксированной точностью.

```python
type(3)      # <class 'int'>
type(3.0)    # <class 'float'>
type(3 / 1)  # <class 'float'> — деление всегда даёт float
```

Большие числа пишут с подчёркиваниями: `1_000_000` — это миллион, подчёркивания игнорируются.

## Три вида деления

```python
7 + 3    # 10
7 * 3    # 21
7 ** 2   # 49 — возведение в степень
7 / 2    # 3.5 — обычное деление, результат всегда float
7 // 2   # 3    — деление нацело
7 % 2    # 1    — остаток
```

Пара `//` и `%` согласована: `(7 // 2) * 2 + 7 % 2` снова даёт 7. `divmod(7, 2)` возвращает оба значения сразу — кортеж `(3, 1)`.

Отрицательные числа ломают ожидания:

```python
-7 // 2   # -4, а не -3
-7 % 2    # 1
```

`//` округляет **вниз**, к минус бесконечности, а остаток берёт знак делителя. Если нужно отбрасывание к нулю, пишите `int(-7 / 2)` — получится `-3`.

Деление на ноль в любом виде — `5 / 0`, `5 // 0`, `5 % 0` — бросает `ZeroDivisionError`. Проверяйте делитель до операции.

## Приоритет операций

Степень старше умножения, умножение старше сложения:

```python
2 + 3 * 4      # 14
(2 + 3) * 4    # 20
2 ** 3 ** 2    # 512 — степень правоассоциативна: 2 ** (3 ** 2)
```

Скобки ничего не стоят и сильно проясняют код. Ставьте их везде, где есть намёк на сомнение. Сравнения можно писать цепочкой, как в математике: `1 < score < 10` равно `1 < score and score < 10`.

## Почему 0.1 + 0.2 != 0.3

```python
0.1 + 0.2            # 0.30000000000000004
0.1 + 0.2 == 0.3     # False
```

`float` хранится в двоичном виде, а 0.1 в двоичной записи — бесконечная периодическая дробь. Погрешность накапливается в каждой операции. Два следствия:

- сравнивайте `float` через `math.isclose(a, b)`, а не через `==`;
- деньги храните в минимальных единицах — копейках, то есть в `int`.

## Округление

```python
round(3.14159, 2)   # 3.14
round(2.5)          # 2, а не 3
round(3.5)          # 4
int(3.99)           # 3 — отбрасывание, не округление
```

`round()` применяет «банковское округление» (banker's rounding): значение ровно посередине округляется к ближайшему **чётному**. Поэтому `round(2.5)` даёт 2, а `round(3.5)` — 4. Привычное школьное округление для положительных чисел получают как `math.floor(x + 0.5)`.

`int()` всегда отбрасывает дробь. `math.ceil()` округляет вверх, `math.floor()` — вниз, и оба возвращают `int`.

## Модуль math

```python
import math

math.sqrt(16)                  # 4.0
math.ceil(3.2)                 # 4
math.floor(3.8)                # 3
math.pi                        # 3.141592653589793
math.isclose(0.1 + 0.2, 0.3)   # True
```

`math` подключается одной строкой и закрывает почти все нужды: корни, тригонометрия, логарифмы, факториал, константы `pi` и `e`.

## Типичные ошибки

- `int("3.5")` → `ValueError`. Строку с точкой сначала превращают в `float`.
- Ждёте, что `round(2.5)` даст 3.
- Сравниваете `float` через `==` и получаете `False` на ровном месте.
- Путаете `//` и `int()` на отрицательных числах: `-7 // 2` это `-4`, а `int(-7 / 2)` это `-3`.
