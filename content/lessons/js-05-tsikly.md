## for — когда количество повторений известно

Счётный цикл (counting loop) состоит из трёх частей:

```js
for (let i = 0; i < 5; i++) {
  console.log(i);   // 0, 1, 2, 3, 4
}
```

Инициализация `let i = 0` выполняется один раз. Условие `i < 5` проверяется **перед каждой** итерацией: как только оно стало ложным — цикл завершён. Шаг `i++` выполняется после каждого прохода тела.

Идиома «от 0 до n-1» — `for (let i = 0; i < n; i++)` — встречается в JS постоянно: так перебирают индексы массива, так рисуют сетку, так повторяют действие n раз.

## while — когда количество повторений неизвестно

```js
let balance = 100;

while (balance >= 30) {
  balance -= 30;   // 100 → 70 → 40 → 10, дальше условие ложно
}
```

Условие проверяется до тела цикла. Главное требование: внутри цикла должно происходить что-то, что однажды сделает условие ложным, иначе вкладка зависнет навсегда. Разновидность `do { ... } while (условие)` выполняет тело хотя бы один раз, потому что проверка стоит в конце.

## for...of — перебор значений

Для массивов и строк есть специальный цикл (iteration):

```js
const cities = ['Псков', 'Казань', 'Омск'];

for (const city of cities) {
  console.log(city);   // сами значения, без индексов
}

for (const letter of 'кот') {
  console.log(letter); // 'к', 'о', 'т' — строки тоже можно перебирать
}
```

`for...of` даёт значение элемента, а не его номер. Если нужен и номер, используйте счётный `for` с обращением по индексу: `for (let i = 0; i < cities.length; i++)`.

## for...in — это про ключи, не про значения

`for...in` перебирает **ключи** объекта и достался массивам по наследству:

```js
for (const key in cities) {
  console.log(key);   // '0', '1', '2' — строки, а не города!
}
```

Индексы приходят строками, порядок для обычных объектов не гарантирован, а если кто-то расширил прототип массива, цикл зацепит и лишние свойства. Массивы перебирайте только `for...of` или счётным `for`; `for...in` оставьте для объектов — вернёмся к этому в уроке про объекты.

## break и continue

- `break` — немедленно выйти из цикла.
- `continue` — пропустить остаток итерации и перейти к следующей.

```js
let sum = 0;

for (const n of numbers) {
  if (n < 0) continue;  // отрицательные не считаем
  if (n > 100) break;   // слишком большие — прекращаем совсем
  sum += n;
}
```

## Аналог range из Python

В JS нет встроенного `range`, но есть две идиомы. Первая — счётчик в `for`: `for (let i = 1; i <= n; i++)`. Вторая — создать массив чисел одной строкой:

```js
const nums = Array.from({ length: 5 }, (unused, i) => i + 1); // [1, 2, 3, 4, 5]
```

Стрелочную запись `(unused, i) => i + 1` подробно разберём в следующем уроке; пока достаточно знать, что это маленькая функция «из номера позиции сделай число».

## Частые ошибки

- `for...in` по массиву: получите строковые ключи вместо значений.
- Off-by-one: условие `i <= arr.length` даст на последней итерации `undefined` — нужно `<`.
- Бесконечный `while`: забыли менять переменную из условия.
- Изменение массива прямо во время перебора (`splice` внутри `for...of`) — элементы начнут пропускаться.
- `var` в заголовке `for`: переменная протечёт наружу из цикла; `let` создаёт новую привязку на каждую итерацию — используйте его.
