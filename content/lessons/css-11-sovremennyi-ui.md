## Из чего складывается современный вид

«Современный» интерфейс — это не один приём, а несколько договорённостей: полупрозрачные слои поверх насыщенного фона, мягкие градиентные акценты, крупные скругления, многослойные тени, живой отклик на наведение и щедрые, но ритмичные отступы. Интерфейс этого приложения собран ровно так, и дальше разберём каждый слой.

## Стекло

Glassmorphism — панель, через которую просвечивает фон. Работает из четырёх частей, и убрать можно только одну:

```css
.glass {
  background: rgba(255, 255, 255, .08);
  border: 1px solid rgba(255, 255, 255, .28);
  border-radius: 18px;
  backdrop-filter: blur(16px) saturate(140%);
  box-shadow: 0 24px 60px rgba(0, 0, 0, .45),
              inset 0 1px 0 rgba(255, 255, 255, .22);
}
```

`backdrop-filter` размывает то, что находится **под** элементом. Отсюда два следствия. Фон обязан быть полупрозрачным: непрозрачный `#0b1020` просто закроет подложку, и размывать будет нечего. И позади должно быть что-то контрастное — градиент, цветные пятна или изображение: на ровном сером фоне стекло неотличимо от обычной панели.

`inset`-тень сверху рисует блик на кромке — именно она даёт ощущение толщины стекла.

## Градиенты

Акцентный градиент из двух близких по светлоте цветов выглядит дорого, из двух противоположных — дёшево:

```css
background-image: linear-gradient(135deg, #6366f1, #22d3ee);
```

Угол 135deg — диагональ слева сверху направо вниз, самое частое направление. Градиентом красят кнопки, аватары, полосы прогресса и фоновые пятна. Текст градиентом делают через `background-clip: text` с прозрачным `color`, но читаемость при этом падает — оставьте приём для заголовков.

`radial-gradient` даёт мягкое световое пятно на фоне. Несколько таких пятен с `transparent` в конце и есть «живой» фон:

```css
background:
  radial-gradient(600px 320px at 12% -8%, rgba(99, 102, 241, .3), transparent 62%),
  radial-gradient(500px 300px at 92% 4%, rgba(34, 211, 238, .2), transparent 60%),
  #06070f;
```

## Скругления

Радиусы держат в шкале из трёх-четырёх значений, иначе страница рассыпается:

- 10px — поля ввода, чипы, иконки
- 16px — карточки
- 22px — крупные панели и модальные окна
- 999px — pill: кнопки и бейджи, у которых скругление равно половине высоты

Правило вложенности: радиус внутреннего элемента меньше радиуса внешнего примерно на величину отступа между ними.

## Тени

Один слой тени выглядит плоско. Реальный объект отбрасывает и широкое мягкое пятно, и узкую резкую тень у самой поверхности:

```css
box-shadow: 0 18px 40px rgba(0, 0, 0, .45),
            0 2px 6px rgba(0, 0, 0, .3);
```

На тёмном фоне тень почти не читается — её роль берут на себя тонкая светлая рамка и `inset`-блик. Цветная тень под акцентной кнопкой (`0 12px 28px rgba(99, 102, 241, .35)`) делает её светящейся.

## Состояния

Интерфейс кажется живым, когда откликается. Минимальный набор: `:hover` поднимает элемент на пару пикселей и усиливает тень, `:active` возвращает обратно, `:focus-visible` рисует обводку только при навигации с клавиатуры. Все три идут через `transform`, `opacity`, `filter` и `box-shadow` длительностью 120–200 мс.

## Типичная ошибка

Стеклянная панель на однотонном фоне: `backdrop-filter` подключён, а эффекта нет, потому что размывать нечего. Вторая — десять разных радиусов и пять несочетающихся теней «из разных макетов». Современный вид держится на повторении небольшого набора значений, а не на количестве эффектов.
