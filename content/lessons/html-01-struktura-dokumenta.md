## Страница начинается с DOCTYPE

Первая строка любого HTML-документа:

```html
<!DOCTYPE html>
```

Это не тег, а объявление (doctype). Оно говорит браузеру: перед ним HTML5, отрисовывай страницу в стандартном режиме (standards mode). Без объявления браузер переключается в режим совместимости (quirks mode) — эмуляцию поведения старых браузеров, где бокс-модель и часть CSS работают «как в 2001 году». Страница может выглядеть нормально, а раскладка — внезапно ломаться. Пишется объявление ровно так: коротко, без атрибутов, регистр букв не важен.

## Три обязательных элемента

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Кофейня «Фасоль»</title>
  </head>
  <body>
    <h1>Кофейня «Фасоль»</h1>
    <p>Открыты ежедневно с 8:00 до 22:00.</p>
  </body>
</html>
```

`html` — корень документа, всё остальное живёт внутри него. Атрибут `lang="ru"` сообщает язык текста: поисковики учитывают его при ранжировании по регионам, браузер предлагает перевод, скринридер выбирает русское произношение. Без `lang` синтезатор речи читает кириллицу английской фонетикой.

`head` — невидимая часть страницы: кодировка, заголовок, стили, скрипты, метаданные для поисковиков и соцсетей. `body` — всё, что видит пользователь: текст, картинки, формы, кнопки. Правило простое: элемент показывается на странице — ему в `body`; описывает страницу — в `head`.

## Два метатега, которые нужны всегда

**Кодировка (charset).** `<meta charset="UTF-8">` — обещание браузеру, что текст файла в UTF-8. Тег ставят первой строкой внутри `head` — пока браузер не знает кодировку, он не может корректно разобрать остальное.

**Viewport.**

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Браузеры телефонов по умолчанию притворяются широким монитором: рисуют страницу шириной около 980px и уменьшают её целиком. Текст становится крошечным, сайт нечитаем. С viewport ширина страницы равна ширине экрана устройства, и адаптивная вёрстка работает как задумана. Для любого сайта в 2026 году эта строка обязательна.

## Типичные ошибки

- **Забыли DOCTYPE.** Браузер ушёл в quirks mode, CSS считается по старым правилам, а вы часами правите отступы вместо того, чтобы посмотреть на первую строку.
- **Содержимое в head, метатеги в body.** Часть такого браузер молча перенесёт или проигнорирует: разметка станет невалидной, а стили из body применятся в непредсказуемый момент.
- **Забыли viewport.** На мониторе всё отлично, на телефоне — нечитаемо. Ошибку видно только на реальном устройстве, поэтому она живёт на сайтах годами.
- **Пустой title или «Без названия».** title показывается на вкладке браузера и в сниппете поисковика — это первый текст о вашей странице, который видит человек.
