## viewport: без него ничего не работает

Мобильный браузер по умолчанию рисует страницу в окне шириной около 980px, а потом уменьшает её целиком. Текст становится микроскопическим. Отключает это одна строка в `<head>`:

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

## Медиазапросы

Медиазапрос (media query) применяет блок правил только при выполнении условия:

```css
@media (max-width: 640px) { /* окна уже 640px */ }
@media (min-width: 700px) { /* окна шире 700px */ }
@media (prefers-color-scheme: dark) { /* тёмная тема в системе */ }
@media (hover: none) { /* нет курсора, только палец */ }
```

Условие проверяется по ширине области просмотра, а не по размеру экрана устройства.

## Сначала мобильные

Mobile-first означает: базовые правила описывают узкий экран и действуют всегда, а `@media (min-width: …)` добавляет улучшения, когда место позволяет.

```css
.nav { display: flex; flex-direction: column; gap: 10px; }

@media (min-width: 700px) {
  .nav { flex-direction: row; gap: 18px; }
}
```

Обратный порядок — desktop-first с `max-width` — заставляет описывать сложную раскладку по умолчанию и затем раз за шагом её упрощать. Правил становится больше, а читать их труднее.

Точки перелома выбирают не по моделям телефонов, а по содержимому: сузьте окно и смотрите, где вёрстка начинает ломаться. Три-четыре точки на сайт — норма.

## Единицы измерения

- `px` — абсолютная единица. Хороша для рамок, теней и промежутков.
- `rem` — доля корневого кегля (обычно 16px). Основная единица для шрифтов и отступов: всё масштабируется, если человек увеличил шрифт в настройках браузера.
- `em` — доля кегля самого элемента. Удобен там, где отступ должен расти вместе с текстом.
- `%` — доля размера родителя.
- `vw` и `vh` — процент ширины и высоты области просмотра. `dvh` учитывает выезжающие панели мобильного браузера, `100vh` на телефоне их не учитывает и обрезает низ.
- `ch` — ширина символа «0». `max-width: 62ch` ограничивает длину строки.

## Плавная типографика

`clamp(минимум, предпочтение, максимум)` возвращает среднее значение, но не выходит за границы:

```css
h1 { font-size: clamp(22px, 5vw, 48px); }
```

На телефоне кегль упрётся в 22px, на широком мониторе — в 48px, а между ними будет меняться непрерывно. Никаких скачков на конкретной ширине и никаких четырёх медиазапросов подряд. То же работает для отступов и ширины колонок.

## Что ломается на узком экране

Фиксированная ширина в пикселях (`width: 960px`) даёт горизонтальную прокрутку. Замените на `max-width` с процентом или `min()`. Длинные ссылки и неразрывные слова лечатся `overflow-wrap: break-word`. Картинкам нужен `max-width: 100%`. Мелкие цели для нажатия — меньше 44px — неудобны пальцу.

## Типичная ошибка

Забытый `<meta name="viewport">`. Все медиазапросы написаны правильно, но страница на телефоне всё равно крошечная: браузер честно отрисовал её на 980px и уменьшил. Вторая ошибка — `100vh` для hero-блока на мобильном: адресная панель браузера выезжает и прячется, и низ блока оказывается под ней.
