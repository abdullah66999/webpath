## Grid там, где две оси

Flexbox раскладывает элементы вдоль одной оси, и поперечная подстраивается под содержимое. Grid (CSS Grid Layout) объявляет **обе оси сразу**: вы задаёте дорожки на контейнере, а элементы попадают в ячейки.

Простое правило: полоса навигации, ряд кнопок, содержимое карточки — Flexbox. Страница целиком, галерея, форма с подписями и полями, дашборд — Grid. Они свободно вкладываются друг в друга.

## Дорожки и промежутки

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
```

Без `display: grid` остальные свойства не сработают — это самая частая оплошность. `grid-template-columns` перечисляет ширину колонок, `grid-template-rows` — высоту строк. `repeat(3, 1fr)` сокращает запись трёх одинаковых дорожек.

`gap` задаёт промежуток между дорожками. Как и во Flexbox, он чище внешних отступов: не появляется лишних полей по краям и нечего схлопывать.

## fr — доля свободного места

Единица `fr` (fraction) означает долю места, оставшегося после фиксированных дорожек и промежутков.

- `1fr 1fr` — две равные колонки.
- `220px 1fr` — фиксированный сайдбар и всё остальное под контент.
- `2fr 1fr` — пропорция 2:1.

## Области вместо номеров

`grid-template-areas` рисует раскладку буквально текстом:

```css
.layout {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
  gap: 14px;
}

.head { grid-area: head; }
.side { grid-area: side; }
.main { grid-area: main; }
.foot { grid-area: foot; }
```

Каждая строка в кавычках — ряд сетки, каждое слово — имя области. Точка (`.`) означает пустую ячейку. Переставить сайдбар вправо — правка одной строки, а не четырёх правил с номерами линий.

## Автоматическое размещение

Если ячейку не назначать явно, элементы заполняют сетку по порядку: слева направо и сверху вниз. Управляет этим `grid-auto-flow`. За выравнивание внутри ячейки отвечают `justify-items` (горизонталь) и `align-items` (вертикаль), а `justify-content` и `align-content` двигают весь набор дорожек, когда он уже доступной области.

## Адаптивная сетка без медиазапросов

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 20px;
}
```

`minmax(240px, 1fr)` не даёт колонке стать уже 240px, а `auto-fit` повторяет её столько раз, сколько поместится. Сузьте окно — число колонок уменьшится само, без единого `@media`.

## Типичная ошибка

`grid-template-columns: 1fr 1fr` и длинное неразрывное слово или широкая картинка в одной из колонок: колонка разъезжается, и появляется горизонтальная прокрутка. Причина в том, что у `1fr` минимальный размер по умолчанию равен `auto`, то есть размеру содержимого. Лечится явно: `minmax(0, 1fr)`.

Вторая ошибка — `justify-content` вместо `justify-items`, когда нужно выровнять элементы внутри ячеек, а двигается вся сетка.
