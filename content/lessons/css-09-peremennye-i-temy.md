## Кастомное свойство

Кастомное свойство (custom property) объявляется через два дефиса и читается функцией `var()`:

```css
:root {
  --accent: #6366f1;
  --space: 16px;
}

.btn {
  background: var(--accent);
  padding: var(--space);
}
```

В отличие от переменных препроцессоров, это живое свойство браузера: его можно менять из JavaScript, переопределять на отдельном блоке и читать в DevTools. `:root` — это `<html>`, объявленные там переменные видны всей странице.

Имя выбираете вы, а не браузер, поэтому осмысленные имена важнее коротких: `--text-dim` понятнее, чем `--c2`.

## Область видимости

Кастомные свойства наследуются. Переменная видна на элементе, где объявлена, и у всех его потомков. Это даёт мощный приём: переопределение на контейнере меняет весь компонент.

```css
.btn { --btn-bg: #6366f1; background: var(--btn-bg); }
.btn.danger { --btn-bg: #e11d48; }   /* одна строка — другая кнопка */
```

Отсюда же главная ловушка: объявив переменную внутри `.card`, вы не сможете использовать её в правиле для `.sidebar` — тот не потомок карточки.

## Запасное значение

`var()` принимает второй аргумент:

```css
color: var(--muted, #8b96b8);
```

Если `--muted` нигде не объявлена или невалидна, подставится `#8b96b8`. Запасные значения можно вкладывать: `var(--a, var(--b, #fff))`.

## Темы

Тема — это набор переопределённых переменных, а не отдельный файл стилей:

```css
:root { --bg: #f8fafc; --fg: #0f172a; }
[data-theme="dark"] { --bg: #0b1020; --fg: #e6ebff; }

body { background: var(--bg); color: var(--fg); }
```

Переключение темы сводится к смене атрибута на `<html>` — одной строкой JavaScript. Все остальные правила не меняются вообще.

Системную настройку ловит медиазапрос:

```css
@media (prefers-color-scheme: dark) {
  :root { --bg: #0b1020; --fg: #e6ebff; }
}
```

## Дизайн-токены

Токены (design tokens) — это переменные, которые описывают решения дизайна, а не конкретные места в вёрстке. Их группируют по смыслу:

- цвета: `--bg`, `--surface`, `--border`, `--text`, `--text-dim`, `--accent`
- геометрия: `--r-sm`, `--r-md`, `--r-pill`
- ритм: `--space-1`, `--space-2`, `--space-3`
- тени и шрифты: `--shadow-md`, `--font-ui`, `--font-mono`

Правило простое: в правилах для компонентов не должно оставаться «сырых» цветов и чисел. Если где-то написано `#6366f1` вместо `var(--accent)`, это место не перекрасится вместе с темой.

## Типичная ошибка

Тёмная тема копированием: рядом с каждым правилом появляется парное `.dark .card { … }`. Файл удваивается, а первая же правка разъезжается в двух местах. Правильный путь — вынести все цвета в токены один раз, а потом переопределять только их.

Вторая ошибка — `var()` в условии медиазапроса: `@media (min-width: var(--w))` не работает, условия вычисляются до применения стилей. Третья — объявить переменную внутри одного правила и пытаться прочитать её в соседнем, не являющемся потомком.
