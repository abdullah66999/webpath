## Функция — это значение

В JavaScript функция (function) — полноценное значение: её можно положить в переменную, передать другой функции, вернуть из функции. С этого начинается всё: колбэки в событиях, методы массивов, асинхронность — это функции, которые принимает чужой код.

## Объявление против выражения

```js
// function declaration
function sum(a, b) {
  return a + b;
}

// function expression
const sum = function (a, b) {
  return a + b;
};
```

Поведение почти одинаковое, но есть ключевая разница — **всплытие**. Declaration поднимается до выполнения кода, поэтому вызвать `sum` можно даже выше строки определения. Expression — обычное присваивание: до него функции ещё не существует, и ранний вызов упадёт с ошибкой.

Практический вывод: declaration позволяет не думать о порядке функций в файле; expression удобен, когда функция создаётся по условию или сразу передаётся дальше.

## Стрелочные функции

Стрелочная функция (arrow function) — компактный синтаксис из ES6:

```js
const double = (x) => x * 2;                  // короткий синтаксис: return неявный
const greet = (name) => `Привет, ${name}!`;
const report = (a, b) => {                    // полный синтаксис
  const total = a + b;
  return total;                               // return обязателен
};
```

Три отличия стрелки от обычной функции:

- нет своего `this` — берётся из окружающего кода;
- нет своего `arguments`;
- её нельзя вызвать через `new`.

Короткий синтаксис с фигурными скобками — частая ловушка: `(x) => { x * 2 }` вернёт `undefined`, потому что скобки сделали тело блоком, а `return` никто не написал.

## this и стрелка

У стрелки нет собственного `this`, и это не баг, а средство от багов:

```js
const timer = {
  seconds: 0,
  start() {
    const tick = () => this.seconds++;  // this — объект timer
    tick();
  },
};

timer.start();
timer.seconds; // 1
```

Обычная функция на месте `tick` получила бы свой `this` — `undefined` в строгом режиме или глобальный объект иначе, — в любом случае не `timer`. Стрелка же сохраняет контекст места, где написана. Обратная сторона: стрелку нельзя делать методом объекта — она возьмёт `this` снаружи, а не у объекта.

## Параметры по умолчанию и rest

```js
function power(base, exponent = 2) {
  return base ** exponent;
}

power(5);     // 25 — exponent не передали, сработал дефолт
power(5, 3);  // 125
```

Значение по умолчанию включается, только когда аргумент равен `undefined` — в том числе переданный явно. `0`, `''` и `null` дефолт **не** включают, в отличие от старого трюка с `||`.

Rest-параметр собирает «остальные» аргументы в массив:

```js
function sum(...numbers) {
  let total = 0;
  for (const n of numbers) total += n;
  return total;
}

sum(1, 2, 3); // 6
sum();        // 0 — пустой массив
```

`...rest` может стоять только последним в списке параметров.

## return

`return` возвращает значение и немедленно завершает функцию. Без `return` (или с пустым) результатом будет `undefined`: функция, которая «печатает» результат вместо возврата, бесполезна для дальнейших вычислений.

## Частые ошибки

- Забыли `return` — вызов вернул `undefined`, и дальше по коду поехала арифметика с `NaN`.
- Передали метод как колбэк без привязки: `button.addEventListener('click', counter.inc)` — `this` потерян. Лечится обёрткой `() => counter.inc()` или `counter.inc.bind(counter)`.
- Стрелка как метод объекта: `this` указывает не на объект.
- `const log = (msg) => { console.log(msg) }` возвращает `undefined` — с фигурными скобками нужен явный `return`.
- Значение по умолчанию ждёт «пустого» значения: `count = 1` сработает на `undefined`, но не на `0`.
