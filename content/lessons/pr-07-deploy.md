## Что значит задеплоить

Деплой (deploy) — сделать так, чтобы приложение работало на сервере, доступном из интернета круглосуточно, а не только на вашем ноутбуке. Между «написал локально» и «выкатил» лежит несколько обязательных шагов: конфигурация через окружение, база в облаке, домен и HTTPS.

## Конфигурация через переменные окружения

Всё, что отличается между разработкой и продом, выносится в **переменные окружения**: `SECRET_KEY`, `DATABASE_URL`, флаг `DEBUG`. Это принцип 12-factor: код одинаковый везде, различается только окружение.

```python
import os
SECRET_KEY = os.environ["SECRET_KEY"]
DATABASE_URL = os.environ["DATABASE_URL"]
DEBUG = os.environ.get("DEBUG", "0") == "1"
```

Значения задают в панели хостинга, а не в коде. В репозитории — только `.env.example` без секретов.

## База данных в облаке

SQLite удобна локально, но это один файл без нормального параллельного доступа — для прода она не годится. В проде используют управляемый **PostgreSQL**: хостинг сам крутит сервер, делает бэкапы и отдаёт вам строку подключения `DATABASE_URL`.

Схему меняют **миграциями** (Alembic для Flask+SQLAlchemy, `manage.py migrate` для Django), а не ручными правками таблиц. Применённая руками в проде миграция — путь к рассинхрону схемы и кода.

## Зависимости с версиями

`requirements.txt` обязан быть с зафиксированными версиями (`pip freeze > requirements.txt`). Без версий сервер поставит другие версии пакетов, и «у меня работало» превратится в «на проде упало». Отсутствие `requirements.txt` вообще делает деплой невозможным.

## Домен и HTTPS

Домен регистрируют у регистратора и в DNS направляют на адрес хостинга (A-запись или CNAME). HTTPS обязателен: Let's Encrypt выдаёт сертификаты бесплатно, а многие хостинги включают TLS автоматически.

## Честно про бесплатный хостинг в 2026

Ситуация изменилась, и обещать «бесплатно навсегда» нельзя:

- **Render** — бесплатный тариф урезан: сервис засыпает после ~15 минут простоя, 750 инстанс-часов в месяц, бесплатная Postgres живёт 30 дней. Годится для демо.
- **PythonAnywhere** — бесплатный аккаунт Beginner с января 2026 нужно продлевать каждый месяц, лимиты урезаны. Простой деплой Flask/Django без Docker.
- **Railway** — это кредитный триал: разовые $5 на 30 дней, дальше платно. Не «бесплатно навсегда».
- **Fly.io** — бесплатного тарифа для новых аккаунтов больше нет, только оплата по факту.
- **Oracle Always Free** — щедрость урезали (Ampere теперь 2 OCPU / 12 ГБ), но это по-прежнему самый выгодный бесплатный VPS: полноценный Linux с SSH и Docker.
- **Supabase** — управляемый Postgres бесплатно до 500 МБ, засыпает после недели неактивности.

**Стратегия:** начните бесплатно, чтобы получить работающую ссылку в портфолио, но рассчитывайте, что демо будет засыпать. Для проекта, который должен жить постоянно, закладывайте минимальный платный тариф или бесплатный Oracle VPS (придётся администрировать самому).

## Типичные ошибки

- `SECRET_KEY` и `DEBUG=True` захардкожены в коде и уехали в репозиторий.
- `requirements.txt` без версий или вообще без него.
- SQLite-файл в проде вместо управляемой Postgres.
- Миграции, применённые руками, и статика, раздаваемая через Flask.
- Деплой «с ноутбука по SSH» без CI — невоспроизводимо и ломается.
