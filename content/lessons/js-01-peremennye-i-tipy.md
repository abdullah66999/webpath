## Три ключевых слова

Переменная (variable) — именованная коробка для значения. В JavaScript их создают три ключевых слова: `let`, `const` и `var`.

```js
const appName = 'WebPath';  // константа: переприсваивать нельзя
let score = 0;              // переменная: значение можно менять
score = score + 10;
```

По умолчанию пишите `const` и переходите на `let` только тогда, когда значение действительно будет переприсваиваться. Это не придирка: если большинство переменных — константы, при поиске бага вы просматриваете только те несколько мест, где стоит `let`.

`var` — старый способ объявления, оставленный ради совместимости. В новом коде его не пишут, но в старых учебниках он встречается постоянно, поэтому разницу полезно знать (см. «Частые ошибки»).

## Типы и typeof

В JS семь примитивных типов (primitive) и объекты (object):

- `number` — любое число: `42`, `-3.5`, `0`. Отдельного целочисленного типа нет.
- `string` — текст. Кавычки: одинарные `'привет'`, двойные `"привет"`, обратные (шаблонные) — про них подробнее в уроке про строки.
- `boolean` — `true` и `false`.
- `undefined` — «значение не присвоено».
- `null` — «пусто, и это умышленно».
- `bigint` — целые числа за пределами точности `number`.
- `symbol` — уникальные идентификаторы; пока просто знайте, что они есть.
- `object` — всё составное: обычные объекты, массивы, функции-значения, даты.

Оператор `typeof` возвращает тип значения строкой:

```js
typeof 42;        // 'number'
typeof 'курс';    // 'string'
typeof true;      // 'boolean'
typeof [1, 2];    // 'object' — массив лишь частный случай объекта
typeof null;      // 'object' — баг языка с 1995 года
```

В отличие от Python, тип принадлежит значению, а не переменной: одна и та же `let` может хранить то число, то строку. Динамическая типизация удобна, пока вы сами следите, что лежит в переменной.

## Приведение типов

JavaScript агрессивно преобразует типы сам (type coercion):

```js
'350' * '3';   // 1050 — умножение привело строки к числам
'350' + '3';   // '3503' — плюс со строкой склеивает!
```

Плюс — единственный оператор, который тянет операнды в строки: если хотя бы один операнд строка, результатом будет строка. Остальные (`-`, `*`, `/`, `%`) приводят к числу. Преобразовать вручную можно функциями `Number('42')`, `String(42)`, `Boolean(0)`.

`Number('abc')` вернёт особое значение `NaN` (Not-a Number). Любопытно, что `typeof NaN` — это `'number'`, а сам `NaN` не равен ничему, включая себя. К этим странностям мы вернёмся в уроке про операторы.

## undefined против null

`undefined` возникает само: переменная объявлена без значения, функция ничего не вернула, у объекта нет такого свойства. `null` программист присваивает сам, как осознанное «ничего». При нестрогом сравнении `null == undefined` даёт `true`, но их типы различаются, и `===` вернёт `false`.

## Частые ошибки

`var` и всплытие (hoisting):

```js
console.log(price); // undefined — и никакой ошибки!
var price = 100;
```

Объявление `var` интерпретатор поднимает в начало области видимости до выполнения кода. Переменная уже существует, но ещё равна `undefined`. С `let` и `const` тот же код упал бы с `ReferenceError` — и это хорошо: ошибка раньше, чем молчаливая неверность. Второй минус `var` — он не видит границ блока: переменная, объявленная внутри `if`, протечёт наружу. Обе проблемы исчезают с `let`, поэтому `var` больше не пишут.

Ещё две ловушки этого урока: `typeof null === 'object'` (наследственный баг, проверяйте `value === null`) и иллюзия, что `const` замораживает само значение. `const` запрещает только переприсваивание: свойства объекта, лежащего в `const`, менять можно — разберём это в уроке про объекты.
