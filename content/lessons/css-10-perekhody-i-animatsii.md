## Переход между двумя состояниями

`transition` описывает, как свойство меняется из старого значения в новое. Сам переход запускается событием — наведением, фокусом, сменой класса.

```css
.btn {
  background: #6366f1;
  transition-property: background-color;
  transition-duration: 0.25s;
  transition-timing-function: ease-out;
}

.btn:hover { background: #4f46e5; }
```

Чаще пишут сокращением, где значения перечислены через пробел, а несколько свойств — через запятую:

```css
.btn { transition: background-color .25s ease-out, transform .18s ease-out; }
```

`transition-delay` добавляет задержку. `transition: all .2s` выглядит удобно, но заставляет браузер следить за всеми свойствами сразу — лучше перечислять нужные.

Длительность подбирают на глаз: 120–200 мс для реакции на наведение, 250–400 мс для появления панелей, больше полусекунды — уже заметно долго.

## Что анимировать дёшево

Браузер рисует кадр в три этапа: раскладка (layout), отрисовка (paint), композитинг (composite). Свойства попадают в разные этапы, и от этого зависит цена анимации.

- **Дёшево:** `transform`, `opacity`, `filter`. Меняются только на этапе композитинга — элемент уже лежит в своём слое, браузер просто сдвигает или просветляет готовый растр.
- **Дорого:** `width`, `height`, `top`, `left`, `margin`, `padding`, `font-size`. Каждый кадр пересчитывает геометрию, а за ней тянется вся страница.
- **Средне:** `background-color`, `box-shadow`, `border-radius` — требуют перерисовки, но не пересчёта раскладки.

`transform: translateY(-4px)` и `margin-top: -4px` выглядят похоже, но первое не двигает соседей и не пересчитывает раскладку. Для анимаций выбирайте `transform`.

## Ключевые кадры

Когда состояний больше двух или анимация должна идти сама, без события, используют `@keyframes`:

```css
.dot { animation: pulse 1.6s ease-in-out infinite; }

@keyframes pulse {
  0%   { opacity: 1;    transform: scale(1); }
  50%  { opacity: .35;  transform: scale(.8); }
  100% { opacity: 1;    transform: scale(1); }
}
```

Сокращение `animation` включает имя, длительность, функцию, задержку, число повторов и направление. Отдельные свойства — `animation-name`, `animation-duration`, `animation-iteration-count`, `animation-fill-mode`. Значение `infinite` зацикливает анимацию, `forwards` оставляет элемент в состоянии последнего кадра.

## Функции transform

`translateX()`, `translateY()`, `scale()`, `rotate()`, `skew()` комбинируются в одном объявлении через пробел, и порядок важен: `translateX(50px) scale(.5)` и `scale(.5) translateX(50px)` дают разный результат. Проценты в `translate` считаются от размера самого элемента — на этом держится центрирование `transform: translate(-50%, -50%)`.

`transform` не влияет на раскладку: место под элемент остаётся прежним, поэтому соседи не ездят.

## Доступность

Бесконечная анимация и резкие сдвиги укачивают. Настройку системы учитывает медиазапрос:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}
```

Это тот редкий случай, где `!important` уместен: правило должно перебить любую авторскую анимацию.

## Типичная ошибка

Анимируют `top` и `width` там, где подошли бы `transform` и `scale`. На простой странице разница незаметна, на странице со списком из двухсот карточек каждый кадр пересчитывает всю раскладку, и анимация идёт рывками. Вторая ошибка — `transition` на свойстве, которое меняется не при наведении, а при загрузке: перехода не будет, потому что стартового значения в момент применения стилей ещё не существовало.
