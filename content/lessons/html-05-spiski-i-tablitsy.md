## Списки

```html
<ul>
  <li>Молоко</li>
  <li>Хлеб</li>
</ul>

<ol start="3">
  <li>Третий шаг</li>
  <li>Четвёртый шаг</li>
</ol>
```

`ul` (unordered list) — маркированный список, когда порядок не важен: пункты меню, характеристики, теги. `ol` (ordered list) — нумерованный: шаги инструкции, места в рейтинге. Атрибут `start="3"` начинает нумерацию с трёх. `li` (list item) — пункт списка, и он **живёт только внутри `ul`, `ol` или `menu`**.

Списки вкладываются: `li` может содержать дочерний `ul` — так делают многоуровневые меню и древовидные структуры. Отдельно стоит `dl` — список определений (definition list): пары из `dt` (термин) и `dd` (расшифровка), хорош для глоссариев и пар «ключ — значение».

Любое перечисление — это список, даже если маркеры скрыты стилями. Меню из трёх `<div>` с `onclick` работает хуже, чем `ul > li > a`: у списка скринридер объявит «список, три пункта», и пользователь сразу поймёт масштаб.

## Таблица данных

```html
<table>
  <thead>
    <tr>
      <th scope="col">День</th>
      <th scope="col">Тема</th>
    </tr>
  </thead>
  <tbody>
    <tr><td>Пн</td><td>Таблицы</td></tr>
    <tr><td>Вт</td><td>Формы</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="2">Всего часов: 5</td></tr>
  </tfoot>
</table>
```

`tr` — строка (table row), `th` — заголовочная ячейка (table header), `td` — ячейка данных (table data). `thead`, `tbody`, `tfoot` — смысловые части: `thead` браузер повторяет на каждой странице при печати, `tfoot` резервируется под итоги.

`scope="col"` говорит: этот `th` — заголовок столбца (для строки — `scope="row"`). Без `scope` скринридер в широкой таблице может зачитать ячейку не с тем заголовком.

## Объединение ячеек

- `colspan="2"` — ячейка занимает две колонки;
- `rowspan="2"` — ячейка тянется через две строки.

Следите за сеткой: если ячейка растянулась на две колонки, в этой строке должно остаться на одну `td` меньше, иначе таблица разъедется. `rowspan` в больших таблицах путает и людей, и машины — применяйте только когда данные правда сгруппированы.

## Типичные ошибки

- **Таблица для раскладки страницы.** Приём из 2003 года, сегодня — антипаттерн: раскладка не адаптируется, печатается постранично-уродливо, скринридер объявляет дизайн «таблицей на 40 ячеек». Раскладка — это CSS (flexbox, grid), таблица — только данные.
- **`li` вне списка** — невалидная разметка.
- **`<td><b>День</b></td>` вместо `th`** — визуально жирно, семантически пусто: машина не узнает заголовок.
- **Таблица без `thead`** — итоги и заголовки не разделить ни в CSS, ни при печати.
- **`<div>`-сетка «как таблица» для настоящих данных** (тарифы, сравнения) — обратная ошибка: данные должны быть таблицей, чтобы их можно было прочитать построчно.
