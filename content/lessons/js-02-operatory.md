## Арифметика

Здесь всё привычно: `+`, `-`, `*`, `/`, остаток от деления `%` и возведение в степень `**`.

```js
7 % 2;    // 1 — остаток: главный способ проверить чётность
2 ** 10;  // 1024
```

Целочисленного деления в JS нет: `7 / 2` это `3.5`, а чтобы получить `3`, округляйте — `Math.floor(7 / 2)`.

Особая роль у плюса со строками: `'7' + 2` даёт `'72'` — склейку (конкатенацию). Все остальные операторы приводят операнды к числу: `'7' - 2` это `5`, `'7' * 2` это `14`.

## == против ===

Нестрогое равенство (loose equality, `==`) перед сравнением приводит операнды к одному типу. Строгое (`===`) сравнивает как есть — и тип тоже.

```js
'5' == 5;           // true — строка стала числом
'5' === 5;          // false — типы разные
null == undefined;  // true — особое правило
null === undefined; // false
0 == '';            // true — и это будущий баг
```

Правило, которое сэкономит вам часы отладки: **всегда `===`**. Единственное осмысленное исключение — `value == null`, когда нужно одной проверкой поймать и `null`, и `undefined`.

## NaN

`NaN` появляется от бессмысленных вычислений: `Number('abc')`, `0 / 0`, `'пять' * 2`. Главная странность: `NaN` не равен ничему, включая самого себя, поэтому `NaN === NaN` даёт `false`. Проверять на NaN сравнением нельзя — используйте `Number.isNaN(x)`.

## Логические операторы

`&&` (и), `||` (или), `!` (не). У них две особенности.

Первая — короткое замыкание (short-circuit): `&&` не вычисляет правый операнд, если левый falsy, а `||` — если левый truthy. Поэтому запись `user && user.name` не падает на отсутствии `user`.

Вторая — они возвращают не `true`/`false`, а значение одного из операндов:

```js
'чай' && 'мёд';   // 'мёд' — первый truthy операнд определяет результат
'' && 'мёд';      // ''
0 || 'по умолчанию'; // 'по умолчанию' — первый truthy
```

Приоритет: `&&` связывает сильнее, чем `||`, а `!` — сильнее обоих.

## ?. и ??

Опциональная цепочка (optional chaining) `?.` обрывает чтение на `null`/`undefined` и возвращает `undefined` вместо TypeError:

```js
const city = user?.address?.city; // undefined, если чего-то по пути нет
```

Оператор `??` возвращает правое значение **только** для `null` и `undefined` — в отличие от `||`, он не трогает честные `0` и `''`:

```js
const count = input ?? 1; // input === 0 останется нулём, а не превратится в 1
```

## Spread

Троеточие `...` разворачивает массив или объект на составные части — так копируют и объединяют:

```js
const copy = [...original, newItem];
const both = [...first, ...second];
const merged = { ...defaults, ...userSettings };
```

Копия поверхностная (shallow): вложенные объекты не дублируются, а разделяются между оригиналом и копией.

## Частые ошибки

- `'5' == 5` проходит тесты и ломается в продакшене: нестрогое сравнение непредсказуемо (`'' == 0`, `[] == false`, `[null] == false`).
- `if (x === NaN)` не сработает никогда — только `Number.isNaN(x)`.
- Цепочка `a.b.c` без `?.` падает с TypeError, если промежуточное звено оказалось `null`.
- В `{ ...a, ...b }` при одинаковых ключах побеждает `b`: поздний spread перезатирает ранний.
- `[] + []` равно `''`: объекты приводятся к примитивам, массив — к своей строке.
