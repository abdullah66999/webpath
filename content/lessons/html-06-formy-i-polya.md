## Как работает форма

```html
<form action="/feedback" method="post">
  <label for="email">Эл. почта</label>
  <input type="email" id="email" name="email">
  <button type="submit">Отправить</button>
</form>
```

При отправке браузер собирает значения всех полей с атрибутом `name`, формирует HTTP-запрос и отправляет его по адресу из `action`. `method` задаёт метод HTTP:

- `get` — данные сериализуются в строку запроса URL: `/search?q=кот`. Запрос можно сохранить в закладки, поделиться ссылкой. Используется для поиска и фильтров — операций, которые ничего не меняют.
- `post` — данные уходят в тело запроса, в URL их не видно. Используется для всего, что меняет данные на сервере: регистрация, заказ, комментарий. Пароли в URL светиться не должны — они попадают в историю браузера и серверные логи.

Ключевой атрибут поля — `name`, именно под этим ключом значение придёт на сервер. **Поле без `name` не отправляется.** `id` нужен браузеру, скриптам и связке с `label` — сервер его не видит.

## input и его типы

`type` — не только внешний вид:

- `text`, `email`, `password`, `number`, `tel`, `date`, `url`, `search` — браузер включает встроенную проверку формата, а телефон показывает подходящую клавиатуру: цифры для `tel`, «собаку» для `email`.
- `checkbox` — одиночный переключатель («согласен с условиями»).
- `radio` — выбор одного из группы: все кнопки группы обязаны иметь **одинаковый `name`**, тогда выбор одной снимает остальные.
- `file` — выбор файла (форме нужен `enctype="multipart/form-data"`).
- `hidden` — значение, которое пользователь не видит. Это не способ передать секрет: оно так же легко подделывается, как и любое другое поле.

## label обязателен

```html
<label for="city">Город</label>
<input id="city" name="city">
```

`for` совпадает с `id` поля — и они становятся одним целым: скринридер объявляет «Город, поле редактирования», клик по тексту подписи ставит курсор в поле, область попадания увеличивается. Альтернатива — вложить `input` прямо в `label`, это тоже корректно.

`placeholder` — временная подсказка внутри поля. Он исчезает при вводе, плохо читается на светлом фоне и не заменяет подпись. Правило: у каждого поля есть видимый `label`.

## select и textarea

```html
<label for="topic">Тема</label>
<select id="topic" name="topic">
  <option value="bug">Ошибка на сайте</option>
  <option value="idea">Предложение</option>
</select>

<label for="text">Сообщение</label>
<textarea id="text" name="text" rows="4"></textarea>
```

На сервер из `select` уходит атрибут `value` выбранного `option`, а не текст, который видит человек. `textarea` — многострочное поле; стартовый текст пишется между открывающим и закрывающим тегом.

## Типичные ошибки

- **Форма без `label`** — поля «подписаны» только placeholder'ом: для скринридера форма безымянная.
- **`<div class="button">Отправить</div>` вместо `<button>`** — не нажимается с клавиатуры, не фокусируется, не отправляет форму.
- **`button` без `type` внутри формы** — по умолчанию он `submit`; кнопка «очистить» неожиданно отправит форму.
- **Забыли `name`** — значение молча не доходит до сервера, и вы час ищете баг в бэкенде.
- **Одинаковые `name` у полей, которые не являются radio-группой** — значения перезатирают друг друга.
