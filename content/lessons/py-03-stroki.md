## Строка — это последовательность символов

Одинарные и двойные кавычки равнозначны, тройные нужны для многострочного текста:

```python
name = "Аня"
city = 'Казань'
note = """первая строка
вторая строка"""
```

Если внутрь текста нужна сама кавычка, оберните строку в другие кавычки: `'Он сказал: "привет"'`.

## f-строки

f-строка (formatted string literal) подставляет результат выражения прямо в текст:

```python
product = "Кофе"
price = 199.5
print(f"{product} — {price:.2f} руб.")   # Кофе — 199.50 руб.
```

В фигурных скобках может быть любое выражение, а после двоеточия — формат вывода:

- `:.2f` — два знака после запятой;
- `:,` — разделители тысяч: `f"{1234567:,}"` даст `1,234,567`;
- `:<10`, `:>10`, `:^10` — выравнивание по ширине;
- `:.1%` — процент с одним знаком: `f"{0.856:.1%}"` даст `85.6%`.

До f-строк текст собирали конкатенацией `"a" + str(x)` и методом `format()`. Сегодня f-строки — способ по умолчанию: короче и не нужно помнить про `str()`.

## Индексация и срезы

Отсчёт символов идёт с нуля, отрицательный индекс считает от конца:

```python
url = "https://example.com/page"
url[0]      # 'h'
url[-1]     # 'e'
url[:5]     # 'https'
url[8:]     # 'example.com/page'
url[8:19]   # 'example.com'
url[::-1]   # 'egap/moc.elpmaxe//:sptth' — строка задом наперёд
```

Срез (slice) пишется `[start:stop:step]`, причём `stop` в результат **не входит**: `url[8:19]` — это символы с 8-го по 18-й. Пустой `start` означает «с начала», пустой `stop` — «до конца». Шаг `-1` разворачивает последовательность; именно так в одну строку проверяют палиндром: `word == word[::-1]`.

Разница в поведении важная: индекс за границами строки бросает `IndexError`, а срез — никогда. `"abc"[1:100]` спокойно вернёт `'bc'`.

## Методы строк

Строка **неизменяема** (immutable): любой метод возвращает новую строку, исходная остаётся нетронутой.

```python
email = "  Anna@Gmail.Com "
print(email.strip().lower())   # anna@gmail.com
print(email)                   # '  Anna@Gmail.Com ' — не изменилась
```

Набор, который нужен почти каждый день:

- `upper()`, `lower()`, `capitalize()`, `title()` — регистр;
- `strip()`, `lstrip()`, `rstrip()` — убрать пробелы по краям;
- `split()`, `join()` — разбить на куски и склеить обратно;
- `replace()`, `find()`, `count()`, `startswith()`, `endswith()`;
- `isdigit()`, `isalpha()`, `isspace()` — проверка состава строки.

```python
"python,flask,sql".split(",")   # ['python', 'flask', 'sql']
", ".join(["a", "b", "c"])      # 'a, b, c'
```

`split()` без аргумента делит по любому пробельному промежутку и **не создаёт пустых элементов**: `"a  b".split()` даст `['a', 'b']`. А вот `"a  b".split(" ")` — `['a', '', 'b']`, потому что пустой кусок между двумя пробелами считается отдельным.

## Экранирование

```python
print("Он сказал: \"привет\"")
print("путь: C:\\Users\\fozzi")
print("первая\nвторая\tстрока")
```

Префикс `r` делает строку «сырой» (raw string) — обратный слэш в ней не экранируется: `r"C:\Users"` содержит ровно то, что написано. Так удобно писать пути и регулярные выражения.

## Типичная ошибка

```python
name = "аня"
name.upper()     # вернуло 'АНЯ' — и результат пропал
print(name)      # 'аня'
```

Строку нельзя изменить на месте. Результат метода нужно присвоить обратно: `name = name.upper()`. Забытое присваивание — самая частая причина «метод не сработал».
