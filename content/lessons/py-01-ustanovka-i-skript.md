## Поставить интерпретатор

Python — это программа, которая читает ваш код и выполняет его строка за строком. Всё, что нужно на старте: установить её и научиться запускать файлы.

- **Windows.** Скачайте установщик с python.org, запустите и на первом же экране поставьте галочку **Add python.exe to PATH**. Без неё терминал не узнает команду `python`.
- **macOS.** `brew install python` или тот же установщик с python.org. Команда называется `python3`.
- **Linux.** Интерпретатор обычно уже в системе, доустанавливается через `sudo apt install python3`.

Проверка везде одинаковая:

```bash
python --version
```

Ответ вида `Python 3.13.1` означает, что всё получилось. Если Windows пишет «python не является внутренней или внешней командой» — галочку PATH вы не поставили. Переустановить быстрее, чем править переменные окружения руками.

## Первый скрипт

Скрипт (script) — обычный текстовый файл с расширением `.py`. Создайте папку `py`, а в ней файл `hello.py`:

```python
print("Привет, Python!")
print("Файл называется hello.py")
```

Запуск — из терминала, в той же папке:

```bash
python hello.py
```

Расширение `.py` обязательно: по нему редактор включает подсветку синтаксиса. Windows любит прятать расширения, и тогда файл на диске называется `hello.py.txt`, а запуск падает с «can't open file».

## REPL: быстрый разговор с интерпретатором

Если набрать `python` без аргументов, вы попадёте в REPL (read–eval–print loop) — режим, где выражение выполняется сразу после Enter.

```text
>>> 2 ** 10
1024
>>> print("так можно")
так можно
>>> exit()
```

REPL нужен, чтобы проверить догадку за секунду: что вернёт метод, какой у значения тип. Код из REPL исчезает вместе с сессией — всё, что хочется сохранить, пишется в файл. Выход: `exit()` или Ctrl+Z (Windows) / Ctrl+D (Linux и macOS).

## print умеет больше

```python
print("2026", "04", "15", sep="-")   # 2026-04-15
print("загрузка", end="... ")        # без перевода строки
print("готово")                      # загрузка... готово
```

`sep` — разделитель между аргументами (по умолчанию пробел), `end` — то, что печатается в конце (по умолчанию перевод строки).

Строку можно повторять: `"-" * 20` даст линию из двадцати дефисов.

## Где чаще всего спотыкаются

- Запустили `python hello` без расширения — файл не найден.
- Написали код в редакторе и не сохранили: интерпретатор читает то, что лежит на диске, а не то, что на экране.
- Держат проект в папке с пробелами и кириллицей и запускают скрипт из другой директории — путь не находится. Заведите простой путь вроде `C:\Users\имя\py`.
- Написали `print "текст"` по образцу Python 2. В третьей версии `print` — функция, скобки обязательны.

## Что дальше

Скрипт печатает готовые строки. Чтобы считать и хранить данные, нужны переменные — имена, типы и приведение одного типа к другому.
