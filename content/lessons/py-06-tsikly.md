## for обходит то, что можно перебрать

```python
for letter in "питон":
    print(letter)
```

Цикл `for` в Python означает не «повтори N раз», а «возьми каждый элемент». Он работает со строками, списками, словарями, множествами — всем, что итерируемо (iterable). Переменная цикла остаётся живой и после него: в примере выше `letter` в конце равно `"н"`.

## range

Когда нужны именно числа или фиксированное количество повторов, берут `range()`:

```python
for i in range(3):
    print(i)        # 0, 1, 2

range(2, 8)         # 2, 3, 4, 5, 6, 7 — stop не входит
range(2, 8, 3)      # 2, 5
range(8, 2, -1)     # 8, 7, 6, 5, 4, 3
```

`range` ленивый: список в памяти он не создаёт, а выдаёт числа по одному. Если список всё-таки нужен, напишите `list(range(5))`.

Главная ловушка — `stop` не включается. Чтобы дойти до `n`, пишите `range(1, n + 1)`.

## while: пока условие истинно

```python
balance = 1000.0
months = 0
while balance <= 1500:
    balance *= 1.05
    months += 1
print(months)      # 9
```

`while` выбирают, когда число повторений заранее неизвестно. У него обязан быть выход: что-то внутри тела должно приближать условие к ложному. Иначе цикл бесконечный, и терминал придётся останавливать через Ctrl+C.

## break и continue

`break` немедленно выходит из цикла, `continue` пропускает остаток тела и переходит к следующей итерации:

```python
for n in range(1, 100):
    if n % 7 == 0 and n % 5 == 0:
        print(n)          # 35
        break

for n in range(5):
    if n % 2 == 0:
        continue
    print(n)              # 1, 3
```

`break` прерывает только тот цикл, в котором написан. Из вложенного наружу он не выпрыгивает.

## else у цикла

Неожиданная конструкция: `else` после `for` или `while` выполняется, если цикл завершился сам, **без** `break`.

```python
for n in [4, 6, 8]:
    if n % 5 == 0:
        print("есть кратное пяти")
        break
else:
    print("кратных пяти нет")
```

Так удобно писать поиск: «перебрал всё — и не нашёл».

## Аккумулятор

Типовой приём — переменная, которая накапливает результат:

```python
total = 0
for price in [120, 45, 300]:
    total += price
print(total)      # 465
```

Аккумулятор создают **до** цикла. Объявленный внутри, он будет сбрасываться на каждой итерации.

## enumerate вместо range(len(...))

Если нужны и элемент, и его номер:

```python
names = ["Аня", "Марк"]

# так писать не нужно
for i in range(len(names)):
    print(i, names[i])

# так — нужно
for i, name in enumerate(names):
    print(i, name)

for i, name in enumerate(names, start=1):
    print(i, name)      # нумерация с единицы
```

`enumerate` читается быстрее и не даёт ошибиться в индексе. Параллельный обход двух последовательностей делает `zip(names, scores)` — он обрывается по самой короткой из них.

## Вложенные циклы

```python
for row in range(1, 4):
    for col in range(1, 4):
        print(row * col, end=" ")
    print()
```

Внутренний цикл прокручивается целиком на каждой итерации внешнего, поэтому общее число шагов — произведение длин. Три уровня вложенности и глубже — сигнал, что логику пора выносить в функцию.

## Типичные ошибки

- `while True:` без `break` внутри: цикл висит навсегда.
- Изменяете список, по которому идёт цикл: часть элементов будет пропущена. Перебирайте копию `for x in items[:]` или собирайте новый список.
- `range(len(items))` там, где нужен `enumerate`.
- Забыли, что `range(a, b)` не включает `b`.
- Ожидаете, что один `break` выключит два вложенных цикла сразу.
