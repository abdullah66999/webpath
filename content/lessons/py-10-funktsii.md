## Зачем нужны функции

Пока код короткий, его можно писать подряд. Как только одно и то же действие встречается во второй раз, копипаста начинает мстить: исправлять придётся в пяти местах, и в одном вы обязательно забудете.

Функция решает три задачи сразу:

- **Убирает повторение.** Логика написана один раз, вызывается сколько угодно.
- **Даёт имя.** `calculate_discount(order)` читается быстрее, чем десять строк арифметики.
- **Изолирует.** Внутри функции свои переменные, наружу попадает только результат.

## Объявление и вызов

```python
def greet(name):
    return f"Привет, {name}!"

message = greet("Аня")
print(message)
```

Разберём по частям:

- `def` — ключевое слово, объявляющее функцию.
- `greet` — имя. Пишется в `snake_case`: маленькие буквы, слова через подчёркивание.
- `(name)` — **параметры**: переменные, которые функция ждёт на входе.
- `return` — отдаёт значение наружу и **сразу завершает** функцию. Всё, что написано после `return` в той же ветке, не выполнится никогда.
- `greet("Аня")` — вызов. `"Аня"` здесь **аргумент**: конкретное значение, которое попадает в параметр `name`.

Параметр и аргумент — разные вещи. Параметр описан в объявлении и всегда один; аргументов может быть много за разные вызовы.

## Что возвращает функция без return

`return` не обязателен. Если его нет, функция возвращает `None`.

```python
def show(title):
    print("=== " + title + " ===")

result = show("Отчёт")   # печатает строку
print(result)            # None
```

Это частый источник путаницы: `print` выводит текст на экран, `return` отдаёт значение программе. Функция, которая печатает результат вместо возврата, бесполезна для дальнейших вычислений — её ответ нельзя ни сохранить, ни передать другой функции.

Правило простое: **если результат нужен кому-то ещё — возвращайте, если только человеку на экран — печатайте.**

## Значения по умолчанию

Параметру можно задать значение, которое подставится, если аргумент не передали.

```python
def price(amount, discount=0, currency="руб"):
    total = amount * (1 - discount / 100)
    return f"{total:.2f} {currency}"

price(1000)                    # '1000.00 руб'
price(1000, 15)                # '850.00 руб'
price(1000, discount=15)       # то же, но читается яснее
price(1000, currency="USD")    # discount остался нулевым
```

Параметры по умолчанию **обязаны идти после обязательных**. Запись `def f(a=1, b)` — синтаксическая ошибка: интерпретатор не поймёт, куда девать второй позиционный аргумент.

Когда аргументов больше двух, передавайте их по имени: `price(1000, discount=15)` понятнее, чем `price(1000, 15)`. Через полгода вы не вспомните, что означала пятёрка.

## Ловушка изменяемого значения по умолчанию

```python
def add_item(item, basket=[]):     # так делать нельзя
    basket.append(item)
    return basket

add_item("яблоко")   # ['яблоко']
add_item("груша")    # ['яблоко', 'груша'] — неожиданно!
```

Значение по умолчанию создаётся **один раз** — в момент объявления функции, а не при каждом вызове. Один и тот же список переиспользуется во всех вызовах, и состояние накапливается.

Правильно так:

```python
def add_item(item, basket=None):
    if basket is None:
        basket = []
    basket.append(item)
    return basket
```

Ловушка касается только изменяемых объектов: списков, словарей, множеств. Числа, строки и `None` неизменяемы, с ними проблемы нет.

## Ранний выход

`return` в середине функции — нормальный приём. Он позволяет разобрать особые случаи сверху и не наращивать вложенность `if`.

```python
def divide(a, b):
    if b == 0:
        return None          # особый случай разобрали и вышли
    return a / b             # основная ветка без лишних отступов
```

Без раннего выхода получилось бы `if b != 0: return a / b else: return None` — то же самое, но с лишним уровнем вложенности. Чем меньше вложенности, тем легче читать.

## Как дробить задачу на функции

Функция должна делать одно дело. Хороший признак: вы можете описать её назначение одним предложением без слова «и».

```python
# плохо: одна функция делает три вещи
def process(order):
    total = sum(i["price"] * i["qty"] for i in order)
    if total > 5000: total *= 0.9
    print(f"Итого: {total}")
    save_to_db(order, total)

# хорошо: каждое действие названо отдельно
def order_total(order):
    return sum(i["price"] * i["qty"] for i in order)

def apply_discount(total, threshold=5000, rate=0.1):
    return total * (1 - rate) if total > threshold else total
```

Второй вариант длиннее по строкам, но короче по смыслу: каждую функцию можно проверить отдельно и переиспользовать в другом месте.
