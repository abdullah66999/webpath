## Список — изменяемая коллекция

Список (list) — упорядоченная **изменяемая** коллекция: элементы можно добавлять, удалять и заменять, не создавая новый объект.

```python
prices = [120, 45, 300]
prices.append(78)     # [120, 45, 300, 78]
prices[0] = 130       # [130, 45, 300, 78]
```

Внутри могут лежать значения разных типов и другие списки. Пустой список — `[]` или `list()`.

## Индексы и срезы

Работают ровно как со строками: отсчёт с нуля, отрицательный индекс от конца.

```python
nums = [10, 20, 30, 40, 50]
nums[0]      # 10
nums[-1]     # 50
nums[1:3]    # [20, 30] — stop не входит
nums[::2]    # [10, 30, 50]
nums[::-1]   # [50, 40, 30, 20, 10]
len(nums)    # 5
```

Индекс за границами бросает `IndexError`, а срез — никогда: `nums[3:100]` вернёт `[40, 50]`.

## Добавление и удаление

```python
stack = [1, 2, 3]
stack.append(4)        # [1, 2, 3, 4] — один элемент в конец
stack.extend([5, 6])   # [1, 2, 3, 4, 5, 6] — все элементы другого списка
stack.insert(0, 0)     # [0, 1, 2, 3, 4, 5, 6] — вставка по индексу
stack.remove(3)        # удаляет первое вхождение значения 3
last = stack.pop()     # возвращает и удаляет последний
del stack[0]           # удаление по индексу
```

Разница `append` и `extend` — классическая:

```python
a = [1, 2]
a.append([3, 4])   # [1, 2, [3, 4]] — получился вложенный список
b = [1, 2]
b.extend([3, 4])   # [1, 2, 3, 4]
```

Все перечисленные методы меняют список на месте и возвращают `None`.

## b = a — это не копия

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)      # [1, 2, 3, 4] — изменился и a
```

Присваивание не создаёт новый список: оба имени указывают на один объект. Независимую копию дают `a.copy()`, срез `a[:]` или `list(a)`.

Здесь же видна разница `is` и `==`. Первый сравнивает идентичность — тот ли это объект, второй — равенство значений. Для копии `b == a` даст `True`, а `b is a` — `False`. Для `a = [1, 2, 3]` и `c = [1, 2, 3]` результат тот же: значения равны, объекты разные.

Копия получается поверхностной (shallow): вложенные списки остаются общими. Когда это важно, берут `copy.deepcopy()`.

## sort() против sorted()

```python
nums = [3, 1, 2]
nums.sort()                # сортирует на месте, возвращает None
ordered = sorted(nums)     # возвращает НОВЫЙ список, исходный не трогает
sorted(nums, reverse=True)
```

Ловушка: `nums = nums.sort()` присвоит `None`, и список будет потерян. То же самое с `append`.

Сортировать можно по любому признаку через `key`:

```python
words = ["python", "Go", "javascript", "C"]
sorted(words, key=len)         # ['C', 'Go', 'python', 'javascript']
sorted(words, key=str.lower)   # ['C', 'Go', 'javascript', 'python']
```

`key` — функция, чей результат используется при сравнении. Без неё строки сортируются по кодам символов, и все заглавные буквы окажутся раньше строчных.

## list comprehension

Список собирается одним выражением:

```python
squares = [n * n for n in range(5)]              # [0, 1, 4, 9, 16]
evens = [n for n in range(10) if n % 2 == 0]     # [0, 2, 4, 6, 8]
```

Читается справа налево: «для каждого `n` в `range(10)`, если `n` чётное, взять `n`». Короче цикла с `append` и не требует заводить аккумулятор. Злоупотреблять не стоит: два условия и вложенный цикл внутри comprehension читаются хуже обычного `for`.

## Готовые функции

```python
nums = [10, 20, 30]
30 in nums             # True
nums.index(30)         # 2, для отсутствующего значения — ValueError
sum(nums)              # 60
min(nums), max(nums), len(nums)
```

## Типичные ошибки

- `a = a.append(x)` — в `a` окажется `None`, список потерян.
- `b = a` вместо `b = a.copy()` — правки в `b` незаметно портят `a`.
- `nums = nums.sort()` — то же, что и с `append`.
- Удаляете элементы из списка прямо в цикле по нему: индексы съезжают, часть элементов пропускается.
- Ждёте, что `in` найдёт подстроку: `"a" in ["ab", "cd"]` — `False`, потому что сравниваются целые элементы.

## Что дальше

Список хранит данные по порядку. Когда важнее связь «ключ — значение», берут словарь, а для уникальных элементов — множество.
