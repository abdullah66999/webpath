## if, elif, else

Python распознаёт блоки по отступам, а не по фигурным скобкам. Стандарт — 4 пробела.

```python
temperature = -3

if temperature < 0:
    print("Мороз")
elif temperature <= 20:
    print("Тепло")
else:
    print("Жара")
```

- `if` — условие и двоеточие, дальше блок с отступом;
- `elif` — «иначе если», проверяется, только когда предыдущее условие не сработало;
- `else` — всё остальное, без условия, не больше одного и всегда последним.

Как только ветка сработала, остальные пропускаются, даже если тоже подошли бы. Порядок `elif` поэтому важен: проверку `temperature <= 20` нет смысла ставить раньше `temperature < 0`.

Отступ обязателен. Блок без отступа после `if` даёт `IndentationError`, а смесь табов и пробелов в одном файле — `TabError`.

## Сравнения

```python
score = 85
print(score == 85)       # True — равно
print(score != 85)       # False — не равно
print(score < 100)       # True, и так же >, <=, >=
print(0 <= score <= 100) # True — цепочка, как в математике
```

Каждое сравнение возвращает `bool`. Цепочка `0 <= score <= 100` — то же самое, что `0 <= score and score <= 100`.

Отдельно стоит оператор `is`. Он проверяет не равенство значений, а то, что две переменные указывают на один и тот же объект. С числами и строками `is` ведёт себя непредсказуемо из-за внутреннего кэширования, поэтому правило одно: `is` применяют к `None` — `if user is None`.

## and, or, not

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("проходите")
```

`and` истинно, когда истинны оба операнда. `or` — когда хотя бы один. `not` переворачивает значение. Приоритет: `not` старше `and`, `and` старше `or`. Значит, `if not a and b` читается как `(not a) and b`.

Оба оператора «короткие» (short-circuit): в `a and b` второе выражение не вычисляется, если первое ложно. На этом строят защиту:

```python
items = [3, -1]
if items and items[0] > 0:    # items[0] не вычислится на пустом списке
    print("есть положительный")
```

## Ловушка с or

```python
answer = "в"
if answer == "а" or "б":      # всегда истина
    print("да")
```

Python разбирает условие как `(answer == "а") or ("б")`. Первая часть `False`, зато вторая — непустая строка, а она истинна сама по себе. Ветка выполнится при любом `answer`. Правильно так:

```python
answer = "в"

if answer == "а" or answer == "б":
    print("верно")

if answer in ("а", "б"):        # короче и читается лучше
    print("верно")
```

## Truthy и falsy

В условие можно ставить любое значение, а не только сравнение. Ложными (falsy) считаются `False`, `0`, `0.0`, `""`, пустые списки, словари и множества, а также `None`. Всё остальное истинно (truthy).

```python
items = []
if not items:
    print("корзина пуста")

name = "Аня"
if name:
    print("имя задано")
```

Строка из одного пробела `" "` — **истинна**: в ней есть символ. Если значение приходит от пользователя, сначала `strip()`. А когда важно отличить ноль от отсутствия значения, проверяйте явно: `if count is None`.

## Guard clause: особые случаи сверху

Вложенные `if` читаются тяжело. Плоская цепочка `elif` с ранними проверками (guard clause) убирает уровни отступов:

```python
age = 0
is_banned = False

if age <= 0:
    verdict = "нет данных"
elif is_banned:
    verdict = "доступ закрыт"
elif age < 18:
    verdict = "детский тариф"
else:
    verdict = "полный доступ"
```

Тот же код через вложенность занял бы три уровня `if` внутри `if`. Правило простое: одна проверка — одна ветка, а особые случаи разбираются первыми.

## Типичные ошибки

- `if x = 5:` — `SyntaxError`. Присваивание и сравнение пишутся по-разному.
- Забыли двоеточие после условия или отступ у тела блока.
- `if answer == "а" or "б":` — условие всегда истинно.
- Сравниваете с `None` через `==` вместо `is`.
- Ставите `if value:` там, где ноль — осмысленное значение, а не «отсутствие данных».
