## Имя вместо значения

Переменная (variable) — это имя, привязанное к значению. Присваивание не «кладёт данные в коробку», а вешает ярлык:

```python
price = 199
price = price + 50     # теперь имя price указывает на 249
```

Знак `=` читается как «присвой», а не «равно». За сравнение отвечает `==`.

## Правила имён

- Буквы, цифры и подчёркивание. Начинаться с цифры нельзя: `2fast` — синтаксическая ошибка.
- Регистр имеет значение: `Total` и `total` — два разных имени.
- Соглашение Python — `snake_case`: `user_age`, `total_price`.
- Ключевые слова (`if`, `for`, `class`, `None`, `True`) занимать нельзя.

Имя должно говорить, что внутри. `x` допустим в черновике и плох в коде, который вы перечитаете через неделю.

## Четыре типа, с которых всё начинается

- **`int`** — целое число: `0`, `42`, `-7`.
- **`float`** — число с точкой: `3.14`, `-0.5`.
- **`str`** — строка: `"Аня"`, `'42'`.
- **`bool`** — истина или ложь: `True`, `False`. Пишется с большой буквы, это зарезервированные слова.

Тип значения показывает `type()`:

```python
type(42)      # <class 'int'>
type(4.2)     # <class 'float'>
type("42")    # <class 'str'>
```

Запись `"42"` в кавычках — строка, а не число. Кавычки важнее содержимого.

## Динамическая типизация

Тип принадлежит значению, а не имени. В одной переменной сначала может лежать число, потом строка:

```python
value = 10
value = "десять"
type(value)   # <class 'str'>
```

Это и есть динамическая типизация (dynamic typing). Типов она не отменяет: выражение `10 + "0"` упадёт, а не склеится. Просто объявлять тип заранее не нужно — Python определяет его по значению.

## Приведение типов

Из одного типа в другой переводят функциями `int()`, `float()`, `str()` и `bool()`:

```python
int("42")          # 42
float("4.5")       # 4.5
str(42)            # "42"
int(4.99)          # 4 — дробная часть отбрасывается, а не округляется
```

Если текст не похож на число, будет ошибка:

```python
print(int(float("5.5")))    # 5 — сначала float, потом отбросить дробь
print(int("5.5"))           # ValueError: invalid literal for int()
```

`int()` разбирает только записи целых чисел. Точка внутри строки — всегда повод сначала вызвать `float()`.

## Типичная ошибка

```python
count = 3
label = "Товаров: " + str(count)   # правильно
print(label)                       # Товаров: 3

print("Товаров: " + count)         # TypeError
```

Python не склеивает строку с числом «автоматически», как это делает JavaScript. Оператор `+` для строк — конкатенация, и второй операнд обязан быть строкой. Сообщение `TypeError: can only concatenate str (not "int") to str` вы увидите в первые недели не раз.

Вторая по частоте — обращение к переменной до присваивания. `NameError: name 'total' is not defined` означает ровно то, что написано: такого имени Python ещё не встречал.
