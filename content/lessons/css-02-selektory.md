## Селектор — это адрес

Селектор (selector) отвечает на вопрос «к каким элементам применить объявление». Чем точнее адрес, тем меньше правил нужно и тем реже они конфликтуют.

Базовые селекторы:

- `*` — любой элемент. Годится для сброса `box-sizing`, но не для оформления.
- `p`, `button`, `input` — по тегу. Слишком широко: задевает все абзацы на странице.
- `.card` — по классу. Основной рабочий инструмент.
- `#promo` — по идентификатору. В стилях оформления его избегают: специфичность (1,0,0) потом не перебить.
- `[type="email"]` — по атрибуту. Есть варианты: `[href^="https"]` (начинается с), `[href$=".pdf"]` (заканчивается на), `[class*="btn"]` (содержит).

## Комбинаторы: отношения между элементами

- `.card p` — пробел, потомок на любой глубине.
- `.card > p` — только прямой ребёнок.
- `h2 + p` — первый сосед сразу после `h2`.
- `h2 ~ p` — все последующие соседи того же уровня.

Пробел и `>` путают чаще всего. Если внутри карточки есть вложенный список, `.card li` покрасит и его пункты, а `.card > ul > li` — только верхний уровень.

Отдельная ловушка: `.card.title` без пробела — это один элемент, у которого оба класса, а `.card .title` — потомок. Лишний или пропущенный пробел меняет смысл полностью.

## Псевдоклассы

Псевдокласс (pseudo-class) описывает состояние или позицию элемента и пишется через одно двоеточие.

- `:hover`, `:focus-visible`, `:active` — реакция на курсор и клавиатуру.
- `:first-child`, `:last-child`, `:nth-child(2n)` — позиция среди соседей. `:nth-child(odd)` и `:nth-child(even)` закрывают половину задач про зебра-таблицы.
- `:not(.disabled)` — отрицание.
- `:checked`, `:disabled`, `:required` — состояние формы.

```css
.row:nth-child(even) { background: #f8fafc; }
button:not([disabled]) { cursor: pointer; }
```

## Псевдоэлементы

Псевдоэлемент (pseudo-element) создаёт внутри элемента кусок, которого нет в разметке. Пишется через два двоеточия и **обязательно** требует `content`.

- `::before` и `::after` — декоративные вставки: значки, полосы, кавычки.
- `::first-line` и `::first-letter` — оформление фрагмента текста.
- `::placeholder` — подсказка в поле ввода.
- `::selection` — то, как выглядит выделенный текст.

```css
.price::before { content: "От "; color: #64748b; }
.tip::before { content: ""; width: 4px; background: #6366f1; }
```

Пустая строка в `content` — тоже значение: псевдоэлемент появится, и ему можно задать размеры и фон. Без `content` не будет ничего.

## Группировка

Запятая объединяет селекторы, чтобы не повторять объявления:

```css
h1, h2, h3 { line-height: 1.2; font-weight: 700; }
```

Каждый селектор в группе сохраняет собственную специфичность — группировка её не усредняет.

## Типичная ошибка

Селектор написан верно, а стиль не применяется: элемент не попадает под правило. Причина обычно в том, что класс висит не на том уровне вложенности, или между тегом и классом в разметке опечатка. Проверяйте не «правильный ли CSS», а «нашёл ли браузер элемент» — в DevTools выделенный элемент подсвечивается, а во вкладке Styles видны только те правила, которые реально совпали.

Вторая ошибка — `::before` без `content`. Правило есть в файле, в DevTools оно не перечёркнуто, а на странице ничего не появилось.
